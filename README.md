# 하루 할 일

함께 쓰는 캘린더 감성 투두 웹앱. 아이폰 Safari에서 열고 "홈 화면에 추가"로 앱처럼 사용합니다.

- 이메일/비밀번호 로그인, 이메일 초대로 공동 캘린더 사용
- 누가 추가했는지, 누가 언제 완료했는지 표시
- 월력/주력 전환, 한국 공휴일 자동 계산(음력, 대체공휴일 포함), 창립기념일(4월 둘째 주 금요일)
- 기념일(생일, 결혼기념일, 음력 지원), D-Day(100일 단위, 주년), 기념일 전 할 일 자동 추가
- 밀린 일 자동 이월, 보관함(날짜 없는 일), 완료 기록
- 실시간 동기화 (Supabase)

## 구성
- `index.html`, `app.js`: 프론트엔드 (정적 파일, Vercel 배포)
- `config.js`: Supabase URL과 anon 키
- `supabase/schema.sql`: DB 테이블, 보안 규칙(RLS), 함수
